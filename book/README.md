# The Meaning of Design: Persuasion, Archetypes, and Visual Language

This mini textbook is a short introduction to how products, brands, and experiences create meaning. It explores how people are persuaded, how brands take on recognizable identities, and how visual design communicates values before a person even reads the words.

The book is designed for first-year students who want a practical, thoughtful introduction to persuasion, branding, and design without needing a specialized background.

## How to Use This Guide

Read the chapters in order for the clearest progression from basic ideas to practical application. The recurring white T-shirt example helps connect the chapters, showing how the same object can carry different meanings depending on persuasion, identity, and visual framing.

Use this book as a working reference for thinking about design, brand strategy, and the role of AI in structured creative work. It is meant to be read critically, not passively.
